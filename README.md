# Онлайн-запись для автосервисов и детейлингов — демо (Тверь)

Один шаблон → отдельное приложение под каждый бизнес (своё название, цвета, услуги, иконка).

## Что внутри
- **Клиент:** услуги и цены, запись на дату/время с учётом боксов (двойной записи не будет),
  многодневные работы (керамика, плёнка) — приём утром, бокс занят нужное число дней,
  ассистент «хочу мойку в пятницу после 3» → предлагает свободные окна,
  кнопки «Позвонить / Маршрут / Написать», установка на экран телефона (PWA).
- **Владелец** (`#admin`, демо-PIN 0000): расписание по боксам, загрузка и выручка за день,
  отмена записей, добавление записи по звонку, редактирование цен/длительности/видимости услуг.

## Как добавить новый сервис
1. Скопировать `clients/morrus.json` → `clients/<slug>.json`, поменять название, адрес, телефон, часы, боксы, цвет, услуги.
2. `python build.py` → готово в `dist/<slug>/`.

## Перед отправкой владельцу
- Цены в обоих демо **примерные** (`demoPrices: true`) — сверить с их прайсом (2ГИС, сайт, ВК) или сказать владельцу, что поправит сам в кабинете.
- Количество боксов («Моррус» — 3, «Спец Сервис» — 4) — предположение, уточнить.
- Демо выложить на любой статический хостинг (Vercel / Netlify / GitHub Pages / свой VPS) — нужна https-ссылка.

## Ограничение демо
Записи хранятся в браузере (localStorage): клиент и кабинет видят одни данные только на одном устройстве.
Для продажи нужно подключить общую базу (Supabase, бесплатный тариф) и уведомления владельцу в Telegram —
это следующий шаг.

## Сообщение владельцу (пример)
> Здравствуйте! Сделал для «{Название}» приложение онлайн-записи: {ссылка}
> Клиент открывает по ссылке, видит ваши услуги и свободное время по боксам и записывается сам —
> даже когда вы под машиной и не можете взять трубку. Записи сразу видны вам в кабинете ({ссылка}#admin, PIN 0000),
> цены и услуги меняете сами.
> Посмотрите, пожалуйста, — если пригодится, подключу под вас за 1 день.
