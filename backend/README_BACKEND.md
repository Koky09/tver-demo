# Подключение сервера записи (Google, бесплатно), ~10 минут

Записи всех клиентов хранятся в одной Google-таблице.
Сервер — это Google Apps Script, привязанный к этой таблице.

## 1. Таблица и скрипт
1. Откройте https://sheets.google.com и создайте пустую таблицу, назовите её «Онлайн-запись».
2. В меню выберите **Расширения → Apps Script**.
3. Удалите код-заготовку, вставьте всё содержимое `backend/Code.gs` и сохраните.

## 2. Свойства скрипта
⚙ **Настройки проекта → Свойства скрипта → Добавить свойство**:

| Свойство | Значение |
|---|---|
| `TG_BOT_TOKEN` | токен бота (тот же, что в `.env`) |
| `TG_BOT_USERNAME` | `ivedomlenia_bot` |
| `ADMIN_CHAT_ID` | `1630941684` — сюда будут приходить записи сервисов, у которых ещё не подключён владелец |

## 3. Первый запуск
1. В редакторе выберите функцию `setup` и нажмите **Выполнить**.
2. Google попросит доступ: «Проверить разрешения» → ваш аккаунт → «Дополнительно» → «Перейти в проект» → «Разрешить».
3. В таблице появятся листы `bookings`, `clients` и `services`.

## 4. Публикация
1. Нажмите **Начать развертывание → Новое развертывание → тип «Веб-приложение»**.
2. Укажите «Запуск от имени»: **Я**, «У кого есть доступ»: **Все**.
3. Нажмите «Развернуть» и скопируйте URL, который заканчивается на `/exec`.
4. Впишите его в `settings.json` → `"apiUrl"` (или отдайте Claude).

Если потом меняете `Code.gs`: **Развертывания → Управление → ✏ → Версия: новая → Развернуть**.
URL при этом не меняется.

## Новый клиент купил
1. На листе `clients` впишите строку: `slug` (как в `clients/*.json`), `name`, `boxes`.
2. В таблице выберите меню **Запись → Обновить клиентов**. Скрипт выдаст PIN из 6 цифр и код для Telegram.
3. В `clients/<slug>.json` поставьте `"demo": false`, затем выполните `python build.py` и опубликуйте.
4. Отправьте владельцу:
   - ссылку на сайт;
   - ссылку на кабинет (`.../#admin`) и PIN;
   - просьбу открыть в кабинете вкладку «Ссылка» и нажать «Подключить Telegram».

## Как это работает
- Клиенты видят только занятость боксов. Имена и телефоны видит только владелец по своему PIN.
- Сервер сам выбирает свободный бокс и не даёт записать двоих на одно время.
- После 5 неверных PIN вход блокируется на 15 минут.
- Пока у сервиса не подключён владелец, записи приходят вам (`ADMIN_CHAT_ID`).
